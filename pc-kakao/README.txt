랜드메이커 PC 카톡 읽기 점검

1. ZIP을 모두 압축 해제합니다.
2. Install.cmd를 실행합니다. 관리자 권한은 필요하지 않습니다.
3. 바탕화면 랜드메이커 카톡 점검을 실행합니다.
4. PC 카톡 업무방을 별도 창으로 열고 해당 창을 선택합니다.
5. 읽기 점검 후 실제 대화가 보이는지 확인합니다.
6. JSON 저장 후 랜드메이커 PC 카톡 메뉴에서 가져옵니다.

자동 수집은 아직 시작되지 않습니다. 카톡이 문서 텍스트를 노출하지 않으면 읽지 못할 수 있습니다. 비밀번호 입력, 메시지 전송, 카톡 DB 접근, 외부 업로드를 하지 않습니다. 설치는 사용자 LocalAppData에 프로그램 한 개와 바탕화면 바로가기를 만듭니다. 제거는 바로가기와 LocalAppData의 LandmakerKakao 폴더를 삭제하면 됩니다.

2026-11-18: 한국 리전 비공개 S3 어댑터와 Supabase Edge Function 진입점을 추가했습니다. Cloudflare 계정 없이 사진 API를 배포하는 구성입니다. 네이버 서명·비공개 ACL·오류 처리·함수 경로 검사 3개를 추가했으며 기존 9개를 포함해 12개가 통과했습니다. 모의 API 검사이며 실제 네이버 계정/버킷 연결·기기 검증은 아직 하지 않았습니다. 운영 DB와 운영 사이트에는 사진 기능을 적용하지 않았습니다.

# 랜드메이커 매물 사진 기능 — 구현 및 검증 결과

2026-11-18 / 운영 미반영 개발본

## 완료한 코드

- 휴대폰 갤러리 여러 장 선택, 카메라 입력, JPEG 변환·최대 1920px 리사이즈.
- 700KiB 이하 목표 압축, 360px 썸네일, EXIF/GPS/XMP/IPTC 제거.
- 진행률·실패 표시·수동 재시도. 원본은 업로드하지 않음.
- 기존 매물 고유 ID로 연결, 사진 중복 저장 방지, 한 사진을 여러 매물에 연결.
- 목록 대표사진, 상세 갤러리·확대·좌우 이동, 대표 지정·정렬·삭제 연결 복원.
- 광고 승인·취소, 광고작성에서 승인 사진 조회·다운로드. 내부용은 다운로드 API에서 차단.
- 직원별 읽기·편집·광고승인 권한, 인증을 추가로 요구하는 60초 임시 사진 링크.
- 접근·다운로드·수정·삭제·복원 기록, 사진 수·용량·앱 요청량 표시와 한도 차단.
- 운영 데이터·주소·소유주 연결은 변경하지 않음. 코드만 별도 개발 브랜치에 저장.

## 테스트

| 구분 | 환경 | 결과 |
|---|---|---|
| 사진 API·DB·보안·화면 | 로컬 PostgreSQL 엔진(PGlite), 모의 R2, JSDOM | 9개 테스트 통과 |
| 기존 기능 회귀 | 기존 테스트 모음(매물·호실·상담·카톡 등) | 16개 테스트 통과 |
| 실제 브라우저 압축 | Chrome / 테스트용 4032×3024 이미지 | 1920×1440, 약 40KB; 썸네일 360×270, 약 4KB |
| 실제 브라우저 갤러리 | 테스트용 이미지 2장 | 확대, 1/2→2/2 이동 확인 |
| 실제 Cloudflare R2 | 아직 계정·버킷 미연결 | 미검증 |
| 실제 휴대폰·태블릿 | 아직 실제 기기 시험 전 | 미검증 |
| 운영 반영 | 적용 전 승인 필요 | 미적용 |

단순한 테스트 그림은 압축률이 높아 300KB보다 작습니다. 작은 파일을 목표 용량까지 부풀리지 않습니다. JPEG 사진의 실제 화질·용량과 카메라/HEIC 지원은 기기별 추가 시험이 필요합니다.

로컬 테스트는 업로드→조회→광고승인→다운로드→삭제→복원, 내용 중복, 동일 주소의 서로 다른 ID, 사진 공유 연결의 독립 승인, 읽기 전용 직원의 업로드 거부, 미로그인·권한 없음·만료/변조 링크·다른 직원 링크 사용·광고 승인 취소 후 기존 링크 사용 차단을 검사합니다. DB 직접 접근과 RPC를 anon/authenticated 역할에서 거절하는 것도 실제 PostgreSQL 권한으로 검사했습니다.

## 다음에 필요한 작업

1. Cloudflare 계정의 R2 사용 가능 여부 확인. 새 결제/과금 동의는 승인 후 진행.
2. 비공개 Standard 테스트 버킷과 별도 Supabase 테스트 환경 연결.
3. 직원별 사진 권한과 광고 승인 담당자 지정.
4. 실제 R2에서 PC·휴대폰·태블릿 업로드/권한 시험.
5. 결과 검토 후 운영 DB 변경·배포에 대한 사용자 사전 승인.

R2는 무료 사용량이 포함된 종량제이므로 무료 한도 초과를 자동으로 무조건 막아주는 상품으로 간주하지 않았습니다. 기본 앱 한도는 8GB·월 쓰기 90만·읽기 900만입니다. 표시값은 앱 범위이며 Cloudflare 계정 전체 실제 청구량은 대시보드에서 별도 확인해야 합니다.
